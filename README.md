# Hi, I'm Juan Manuel Méndez Rey 👋

Debian Maintainer (`mendezr`) from Sevilla. I package Go, Rust, Java/Scala and
software from the 80s and 90s, and I enjoy bringing old programs back to life.

- 📦 My Debian packages: [qa.debian.org](https://qa.debian.org/developer.php?login=juan.mendezr%40proton.me)
- 📝 Blog: [vejeta.com](https://vejeta.com/en/)
- 🌀 Debian wiki: [JuanMendezRey](https://wiki.debian.org/JuanMendezRey)
- 🦊 [Salsa](https://salsa.debian.org/mendezr) · [Codeberg](https://codeberg.org/mendezr) · [Launchpad](https://launchpad.net/~vejeta)

## Things I work on

- [stremio-debian](https://github.com/vejeta/stremio-debian): Stremio and libcef (Chromium Embedded Framework) for Debian, with an [apt repository](https://debian.vejeta.com). Stremio is now officially [in Debian](https://tracker.debian.org/pkg/stremio).
- [xwpe](https://codeberg.org/mendezr/xwpe): a Borland-style IDE for the terminal and X11 from 1993, revived with LSP and DAP support. [In Debian](https://tracker.debian.org/pkg/xwpe).
- [conquer](https://github.com/vejeta/conquer): the turn-based strategy game Conquer v4 by Adam Bryant and Ed Barlow, and [conquer-web](https://github.com/vejeta/conquer-web), a web interface for it.
- [stremio-distroless](https://github.com/vejeta/stremio-distroless): hardened Stremio containers for Debian and Wolfi.
- [wolfi-packages](https://github.com/vejeta/wolfi-packages): unofficial Wolfi OS packages, including Stremio and qt5-qtwebengine, among many others, including helper scripts to convert to and from alpine/melange/debian formats.
